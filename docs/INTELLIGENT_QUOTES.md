# Cotizaciones en SIG (solo Ave)

Las cotizaciones viven en **Ave**. El diseño es la **JPG oficial** de Escuela Aves Salento; Ave solo rellena campos dinámicos encima (sin rediseñar).

1. Pide a Ave cotizar (personas, experiencia, fecha…).
2. Claude + catálogo arman el borrador.
3. Se abre la plantilla (imagen) con campos editables.
4. Guardar / Generar PDF (misma imagen + valores).

WhatsApp / Registro no alimentan este flujo.
